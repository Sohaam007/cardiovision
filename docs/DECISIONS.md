# DECISIONS
- Vessels are procedural tubes; no Blender dependency (24-36h deadline).
- P(CAD) >= max(vessel probs) enforced server-side.
- Repeated stratified 5-fold x3 + small fixed grid instead of nested Optuna.
- No shap import in API; use XGBoost pred_contribs.
- Hosting: Vercel (frontend) + Render free (API) + fallback demo mode.
- Dataset: UCI id 411 (Extension), not 412. License rows verified 13 Oct 2026 in 08_ASSETS_LICENSES.md. Downloaded and converted to CSV in `data/raw/z_alizadeh_sani.csv` (303 rows, 59 cols).
- BodyParts3D is optional; procedural heart is the default. Mesh work time-boxed to 1.5 h.
- Hackathon brief `Track_A.pdf` verified against `docs/`: 100% aligned (targets, metrics, exclusion of LAD/LCX/RCA/Cath from inputs, 3D and clinical dashboard requirements, 6-page max report, 3-10 min video).
- GitHub repository initialized at `https://github.com/Sohaam007/cardiovision`.
- Web frontend pinned to React 18 for stable R3F / Drei / Zustand / Recharts interoperability with strict TypeScript.
- `requirements.txt` contains pinned production dependencies without `shap`; `shap` placed exclusively in `requirements-dev.txt`.
- ML-01 Cross-Tabulation & Target Derivation:
  - 100% of Cath=CAD cases (216/216) have >=1 stenotic vessel (86 single-vessel, 67 double-vessel, 63 triple-vessel).
  - 86 of 87 Normal cases (98.85%) have 0 stenotic vessels across all three coronary arteries (LAD, LCX, RCA).
  - Row index 93 clinical observation: 65yo male, EF-TTE 45%, Typical Chest Pain=1, documented as Normal in Cath catheterization summary, but annotated with Stenotic LAD (LCX and RCA Normal). In catheterization adjudication, borderline or intermediate diameter stenosis (~50%) may be noted segmentally in LAD yet categorized overall as non-obstructive CAD by the catheterization panel, or represents a clerical recording artifact. Ground truth for all 303 patients is preserved unaltered without manual tampering: CAD target is derived strictly from `Cath`, and vessel targets are derived strictly from `LAD`, `LCX`, and `RCA` columns.
  - Zero-leakage invariant: All 4 targets (CAD, LAD, LCX, RCA) and raw Cath are strictly excluded from feature matrix X (54 clinical features across 303 rows). Constant feature `Exertional CP` (100% 'N') is dropped.
  - Column name reconciliation (raw CSV vs docs/02_DATASET.md):
    - 'Thyroid disease' in doc -> 'Thyroid Disease' in CSV (title case)
    - 'Weak peripheral pulse' in doc -> 'Weak Peripheral Pulse' in CSV (title case)
    - 'Systolic/Diastolic murmur' in doc -> separate 'Systolic Murmur' and 'Diastolic Murmur' in CSV
    - 'Typical chest pain' in doc -> 'Typical Chest Pain' in CSV (title case)
    - 'Function class' in doc -> 'Function Class' in CSV (title case)
    - 'Q wave' in doc -> 'Q Wave' in CSV (title case)
    - 'ST elevation' in doc -> 'St Elevation' in CSV ('St' prefix)
    - 'ST depression' in doc -> 'St Depression' in CSV ('St' prefix)
    - 'T inversion' in doc -> 'Tinversion' in CSV (no space)
    - 'Poor R progression' in doc -> 'Poor R Progression' in CSV (title case)
    Raw CSV column names are retained directly to ensure full reproducibility and schema stability.
- Process Cleanup (Phase 1):
  - Streamlined workflow to ONE implementer + automated verification gates (pytest, TypeScript check, vite build). Multi-agent adversarial loops removed.
  - Human review marker retained for ML and leakage safety: 'HUMAN REVIEW REQUIRED: <file>' when touching ml/train.py or tests/test_no_leakage.py.
- Feature Order and Schema (Phase 2):
  - Frozen ordered list of 54 features exported to `models/feature_names.json`.
  - Comprehensive clinical metadata exported to `models/feature_schema.json` with evidence-based reference ranges citing AHA, ADA, NKF, WHO, and ASE guidelines.
- Training, Calibration & Serving Pipeline (Phases 3, 4, 5):
  - Demo Holdout: 8 stratified representative patients (2 normal, 2 single-vessel, 2 double-vessel, 2 triple-vessel) isolated prior to model training (leaving N=295 for dev set).
  - Validation: RepeatedStratifiedKFold (5 splits x 3 repeats = 15 folds, random seed 42) with inner 3-fold CV for hyperparameter selection.
  - Calibration: Cross-fitted Platt scaling LogisticRegression(C=1e6) on decision margins yields calibrated probabilities and preserves additive TreeSHAP explainability in log-odds space.
  - Zero shap dependency in production: Native XGBoost `pred_contribs=True` computes exact TreeSHAP values in < 15ms per patient.
  - Constraint: Enforced P(CAD) >= max(P(LAD), P(LCX), P(RCA)) on live predictions and flagged via `meta.cad_adjusted`.
